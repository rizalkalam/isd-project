| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Spoofing | JWT Token | mitigate | Store Refresh Token in HTTPOnly/Secure/SameSite cookie; Access Token in-memory. |

| T-01-03 | Information Disclosure | Auth Errors | mitigate | Return generic "Invalid credentials" rather than specific user/password failures. |
| T-01-SC | Tampering | npm/pip installs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED] packages. |
</threat_model>
