## Phase Goal

**As a** student, **I want to** submit a borrow request, **so that** I can reserve a book without someone else double-borrowing it.

<objective>
Implement the Loan model and student borrow request functionality with pessimistic locking.
Purpose: Enable students to request books while ensuring transactional integrity.
Output: Loan model, borrow request API, and UI integration.
</objective>
